花了挺长时间做的一个项目，感觉终于到了可以分享的阶段。

**项目名**：InkSight（墨鱼AI墨水屏）
**GitHub**：https://github.com/datascale-ai/inksight
**官网**：https://www.inksight.site
**协议**：MIT

### 一句话介绍

ESP32 + 4.2 寸电子墨水屏 → 桌面 AI 信息伴侣，自动刷新显示天气/诗词/AI 简报/AI 画/倒计时等 28 种内容。

![成品展示](https://cdn.jsdelivr.net/gh/AeBoPi/inksight@promotional/docs/promotional/1.jpg)

### 主要特点

1. **28 个内置模式**，全部 JSON 定义，写个 JSON 就能创建新模式
2. **多 LLM 支持**：DeepSeek / 通义千问 / Moonshot，OpenAI 兼容接口
3. **AI 生图**：ArtWall 模式，根据天气/节气生成黑白艺术画
4. **语音对话**：WROOM-32E + 麦克风 + 喇叭 = 桌面 AI 助手（实时 ASR + 流式 TTS）
5. **一站式网站**：浏览器刷固件(WebSerial) + 在线配置 + 模式预览 + 模式广场
6. **无设备 Demo**：没买硬件也能先体验所有模式效果
7. **手机 APP**：Android 客户端 + Wi-Fi OTA 升级
8. **多硬件适配**：C3 Pro Mini / C3 标准 / WROOM-32E，2.9" / 4.2" / 5.83"，黑白 / 四色

![6种模式实拍](https://cdn.jsdelivr.net/gh/AeBoPi/inksight@promotional/docs/promotional/4.jpg)

### 技术栈

- 后端：Python FastAPI + SQLite
- 前端：Next.js 16 + Tailwind CSS v4
- 固件：PlatformIO + Arduino (ESP32)
- AI：OpenAI 兼容接口 + 阿里百炼 ASR/TTS/图像生成

### 硬件成本

典型 BOM 约 220 元（ESP32-C3 ~20 + 4.2 寸屏 ~120 + 驱动板/线材 ~15 + 可选电池 ~15）

---

做这个项目的初衷很简单：桌面上需要一块不会打扰你的屏幕。手机推送太多了，开一个 Dashboard 又觉得太重。墨水屏这种"纸感"的东西放在桌上刚好——安静、不发光、偶尔看一眼就好。

之后加了 LLM 内容生成、加了 AI 画、加了语音交互，感觉项目慢慢长成了一个有意思的形态。
