**开源了一个 AI 墨水屏项目，28种模式+语音对话+模式广场｜InkSight**

花了很长时间做的一个开源项目终于可以跟大家分享了。

核心是 ESP32 + 4.2寸墨水屏，做成一个桌面AI信息伴侣：
- 后端 FastAPI + 多 LLM 支持（DeepSeek/通义/Moonshot）
- 前端 Next.js 16 + Tailwind v4 一站式官网
- 28 个 JSON 定义的内置模式，写个 JSON 就能创建新模式
- 模式广场：社区分享+安装
- 语音对话：WROOM-32E + 麦克风 + 喇叭 = 桌面 AI 助手
- 网页刷机：浏览器里直接 WebSerial 烧录
- 手机 APP：Android 客户端 + OTA 升级

技术栈：Python FastAPI / Next.js / PlatformIO Arduino / SQLite / OpenAI 兼容接口 / 阿里百炼 ASR+TTS

硬件成本约 220 元，支持 C3 Pro Mini / C3 标准板 / WROOM-32E 三种主控，2.9/4.2/5.83 寸三种屏幕尺寸。

**桌面上多了一块「纸」，每天自动换内容，治好了我的信息焦虑**

你有没有觉得，每天盯着手机电脑已经够累了，但桌面上好像又缺点什么？

我给自己做了一块电子墨水屏小伴侣。它不发光，像纸一样温和，放在桌上安安静静的。

早上起来，它显示今天的天气和穿衣建议。
工作的时候，它切换成一句诗或一幅 AI 画。
下班前，它提醒我今天的健身计划。

28种模式自动轮播，也可以自己选。最喜欢的是 AI 画廊模式——每次刷新都生成一幅独特的黑白艺术画，结合当前的天气和节气。

而且居然还能跟它说话（加个麦克风和喇叭），问问天气、聊聊天，它会语音回复，还把对话内容显示在屏幕上。

整套 DIY 下来才 220 元，官网一键刷机配置，不用装任何开发工具。

如果你也想要一块，去 inksight.site 先看看效果~
