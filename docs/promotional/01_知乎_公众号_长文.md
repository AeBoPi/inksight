## 你的桌面，真的需要再多一块屏幕吗？

我们每天被屏幕包围：手机、电脑、平板、手表。它们争先恐后地推送通知、闪烁消息、抢夺注意力。

但有些信息，不需要"打扰"你——它只需要安静地待在那里，等你抬头时一眼看见就好。

**天气**，你出门前瞄一眼。**倒计时**，提醒你某个重要日子还有多远。**一句诗**，让你在写代码的间隙感受片刻宁静。**AI 简报**，帮你用一张卡片了解今天的科技动态。

这就是**墨鱼AI墨水屏**想做的事——不是给你更多信息焦虑，而是用一块纸感的电子墨水屏，把真正有用、有温度的内容，以最克制的方式放进你的视线。

---

## 它是什么？

墨鱼AI墨水屏（InkSight）是一个开源的智能桌面伴侣项目。硬件上，它是一块 ESP32 驱动的 4.2 寸电子墨水屏；软件上，它是一套完整的 AI 内容生成 + 渲染 + 配置系统。

**一句话概括：一块会思考的电子纸。**

它每隔一段时间自动刷新内容，安静地展示当前时段最适合你的信息。不亮屏，不耗电，不打扰——就像一张会自己换内容的纸。

## 28 种内置模式，每一种都精心设计

墨鱼目前内置了 **28 种显示模式**，覆盖从实用工具到氛围内容的方方面面：

### 实用工具类
- **天气看板** — 实时天气 + 穿衣/出行建议，抬头就能看到今天的天气
- **日历** — 月历视图 + 农历/节气/节日
- **便签** — 把重要事项钉在桌面上
- **倒计时** — 考试、生日、纪念日，一眼看到还有多少天
- **习惯打卡** — 每天提醒你坚持的小事
- **健身计划** — AI 帮你生成今日训练内容
- **课程表** — 学生党的桌面好搭档

### 文化氛围类
- **诗词** — 每次刷新一首古诗词，适合中式桌面
- **禅意** — 简短禅语，让忙碌的大脑喘口气
- **斯多葛** — 西方哲学智慧，给自己一点力量
- **每日推荐** — 语录、书籍、冷知识混合推送
- **AI 画廊 (ArtWall)** — AI 生成黑白艺术画，结合当前天气/季节/节气

### AI 智能类
- **AI 简报** — 科技热点与 AI 洞察的精简卡片
- **每日一词** — 学英语/日语的桌面单词卡
- **今日菜谱** — AI 根据季节推荐菜品
- **思维挑战** — 每天一个有趣的谜题或问题
- **AI 对话** — 对着设备说话，AI 实时语音回复（需 WROOM-32E）

而且，你还可以通过 JSON 创建自己的自定义模式，或者去**模式广场**安装社区大神设计的模式。

## 一个网站，搞定一切

很多开源硬件项目的痛点是：买了元件不知道怎么刷固件、配置复杂、预览不了效果。墨鱼把这些全部打通到了一个网站里：

### 🔧 在线刷机
打开浏览器，插上数据线，点几下就能完成固件烧录。不需要装 Arduino IDE，不需要配 PlatformIO，不需要命令行。

### ⚙️ 在线配置
选择你喜欢的模式、设置刷新频率、调整城市/语言/个性化选项——全部在网页上完成。

### 👀 在线预览
保存配置前，先在浏览器里看到实际的墨水屏渲染效果。改了不满意？调整后再预览，直到你满意为止。

### 🎪 模式广场
发现、分享、安装其他用户创作的模式。觉得自己设计的模式很棒？发布到广场，让全世界的墨鱼用户都能用上。

### 🎮 无设备体验
还没买硬件？没关系。你可以先在网站上体验所有模式的效果，决定要不要动手做一台。

## 220 元，动手做一台

墨鱼的硬件方案经过精心优化，提供三种适合不同人群的购买方案：

| 方案 | 特点 | 适合人群 |
|------|------|----------|
| **分体式** | 开发板 + 驱动板 + 裸屏 + 杜邦线 | 新手，接线清晰，最便宜 |
| **一体化** | 板载 ESP32 的驱动板 + 裸屏 | 追求整洁，走线最少 |
| **屏幕模块** | C3 Pro Mini + 集成屏幕模块 | 追求极致薄，体积最小 |

典型 BOM 约 **220 元人民币**，主要成本在屏幕（约 100-130 元）。

支持的硬件组合：
- **主控**：ESP32-C3 Pro Mini / C3 标准板 / WROOM-32E
- **屏幕**：2.9 寸 / 4.2 寸 / 5.83 寸，黑白 / 黑白红 / 四色
- **供电**：USB 或 2000mAh 锂电池（超长待机）

## 语音对话：不只是看，还能「聊」

如果你选择 ESP32-WROOM-32E 开发板，再加一个麦克风模块和小喇叭，墨鱼就变成了一个能跟你对话的 AI 桌面助手：

- 长按按键说话，松开后 AI 语音回复
- 支持单轮和多轮对话
- 可以语音切换显示模式：「切换到天气」「帮我看看日历」
- 对话内容自动渲染成墨水屏卡片

底层调用阿里百炼的实时 ASR + 流式 TTS，响应速度很快，体验流畅。

![语音对话硬件：ESP32开发板 + 麦克风 + 喇叭 + 功放电路 + 语音激活按键](https://cdn.jsdelivr.net/gh/AeBoPi/inksight@promotional/docs/promotional/8.jpg)

## 开源、可扩展、有社区

墨鱼是一个 **MIT 协议** 的完全开源项目：

- **固件**：PlatformIO / Arduino，支持自定义引脚、屏幕驱动、按键逻辑
- **后端**：Python FastAPI，模块化设计，易于扩展
- **Web**：Next.js 16 + Tailwind CSS v4，现代化前端
- **模式系统**：纯 JSON 定义，不写代码也能创建新模式-

社区已经贡献了：
- 多款 3D 打印外壳（MakerWorld 可下载）
- 定制 PCB 驱动板（立创开源硬件平台可查）
- 华为 Nova 14 手机壳墨水屏版本
